# HYPE Trendline Breakout Trading Bot

ربات معاملاتی شکست خط روند برای صرافی Hyperliquid

## استراتژی

```
قیمت
  │   سقف 1
  │     ●╲
  │    ╱  ╲        سقف 2
  │   ╱    ╲         ●╲                     شکست!
  │  ╱      ╲       ╱  ╲                      ↓
  │ ╱        ╲     ╱    ╲      سقف 3        ╱
  │╱          ╲   ╱      ╲       ●╲        ╱
  │            ╲ ╱        ╲     ╱  ╲      ╱
  │             V          ╲   ╱    ╲    ╱
  │            کف 1         ╲ ╱      ╲  ╱
  │                          V        ╲╱
  │                         کف 2      ●  ← ورود
  │                                  کف 3
  │                                 (SL)
  └──────────────────────────────────────► زمان

     ●━━━━━━━━━━●━━━━━━━━━━●
   سقف1       سقف2       سقف3
          خط روند نزولی
```

### منطق استراتژی:
1. پیدا کردن سقف‌ها (Swing Highs)
2. رسم خط روند نزولی از سقف‌ها
3. منتظر شکست خط روند به سمت بالا
4. ورود بعد از شکست
5. استاپ لاس زیر آخرین کف موج شکست
6. تیک پرافیت با R:R = 1:1

## نصب

```bash
# کلون پروژه
cd /home/user/hyperbot

# نصب وابستگی‌ها
pip install -r requirements.txt

# کپی فایل تنظیمات
cp .env.example .env

# ویرایش فایل .env و وارد کردن کلید خصوصی
nano .env
```

## تنظیمات

فایل `config.py` را ویرایش کنید:

```python
# پارامترهای اصلی
SYMBOL = "HYPE"           # ارز
TIMEFRAME = 5             # تایم‌فریم (دقیقه)
RISK_PER_TRADE = 0.02     # ریسک هر معامله (2%)
LEVERAGE = 5              # لوریج
RISK_REWARD_RATIO = 1.0   # نسبت ریسک به ریوارد

# تست‌نت یا مین‌نت
USE_TESTNET = True        # True برای تست، False برای واقعی
```

## اجرا

```bash
python bot.py
```

## فیلترها

ربات از فیلترهای زیر برای جلوگیری از معاملات بد استفاده می‌کند:

| فیلتر | توضیح |
|-------|-------|
| روند کلی | قیمت نباید خیلی زیر EMA باشد |
| Higher Lows | کف‌ها باید بالاتر از قبلی باشند |
| قدرت شکست | شکست باید قوی باشد |
| شیب خط روند | نباید خیلی تند یا صاف باشد |
| مومنتوم | قبل از شکست باید مومنتوم داشته باشیم |

## هشدار

⚠️ **این ربات برای اهداف آموزشی است**

- اول روی Testnet تست کنید
- هرگز با سرمایه‌ای که نمی‌توانید از دست بدهید معامله نکنید
- این ربات تضمینی برای سود نمی‌دهد
- همیشه ریسک خود را مدیریت کنید

## ساختن API Wallet

1. به [app.hyperliquid.xyz](https://app.hyperliquid.xyz) بروید
2. کیف پول خود را وصل کنید
3. از منوی Portfolio → API Wallets → Generate API Wallet
4. Private Key را در فایل `.env` وارد کنید
